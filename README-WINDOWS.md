# تشغيل Mini Market على Windows بدون إنترنت

هذه النسخة تشغّل المتجر محلياً على جهاز Windows باستخدام قاعدة بيانات محلية محفوظة في ملف. بعد اكتمال التثبيت الأول، لا يحتاج التشغيل اليومي إلى الإنترنت. ويمكنه، عند إعداد اختياري، مزامنة البيانات مع Neon عند عودة الاتصال.

## المتطلبات

يلزم Windows 10 أو Windows 11 وPython 3.11 أو أحدث. يحتاج **التثبيت الأول فقط** إلى الإنترنت لتنزيل مكتبات Python. بعد ذلك يعمل البرنامج محلياً دون اتصال.

## التثبيت الأول

1. فك ضغط المشروع في مجلد ثابت، مثل `C:\MiniMarket`.
2. شغّل الملف `install_windows.bat`.
3. انتظر حتى ينتهي تثبيت المكتبات.

## التشغيل اليومي دون إنترنت

شغّل:

```text
start_offline_windows.bat
```

سيفتح الموقع على:

```text
http://127.0.0.1:3000
```

## المزامنة التلقائية مع Neon

لربط النسخة المحلية بالموقع عند عودة الإنترنت، انسخ `.env.windows.example` إلى ملف باسم `.env.windows` في مجلد المشروع، ثم اكتب اسم المستخدم وكلمة مرور المدير للموقع المنشور. سيحاول البرنامج المزامنة كل دقيقتين عند تشغيله. السجلات الجديدة تُضاف تلقائياً، أما الاختلافات في السجلات الموجودة فتُسجّل في **تعارضات المزامنة** لتراجعها يدويًا؛ ولا تُحذف بيانات Neon تلقائياً.

لا ترفع `.env.windows` إلى GitHub؛ فهو يحتوي على كلمة مرور. إذا تغيّرت كلمة مرور المدير، حدّث الملف المحلي.

بيانات التشغيل التجريبية الافتراضية:

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| المدير | `admin` | `Admin@2026` |
| المشرف | `manager` | `Manager@2026` |
| الكاشير | `cashier` | `Cashier@2026` |

غيّر كلمات المرور من داخل النظام قبل الاستخدام الفعلي.

## التخزين والنسخ المحلية

تُحفظ بيانات Windows تلقائياً في:

```text
%LOCALAPPDATA%\MiniMarket\data\local_db.json.gz
```

وتُحفظ النسخ الاحتياطية في:

```text
%LOCALAPPDATA%\MiniMarket\backups
```

يمكن نقل نسخة `market_db_*.json.gz` إلى مجلد النسخ المحلي ثم استخدام شاشة **النسخ الاحتياطية** لاستعادتها. الاستعادة تتطلب كلمة مرور المدير وكتابة `RESTORE_DATABASE`.

## ملاحظات مهمة

Google Drive غير مستخدم في وضع عدم الاتصال. المزامنة مع Neon تحتاج تشغيل ملف Windows وإعداد `.env.windows` مرة واحدة؛ إذا لم يتوفر الإنترنت تبقى البيانات محلية وتُعاد المحاولة تلقائياً لاحقاً.
