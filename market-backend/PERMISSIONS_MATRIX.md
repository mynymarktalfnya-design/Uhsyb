## 🔐 **قواعد خاصة مهمة:**

### **المالك (Owner):**
✅ صلاحية كاملة على كل شيء
✅ الوحيد الذي يمكنه:
  - حذف البيانات (Soft Delete)
  - تعديل الأسعار
  - إدارة المستخدمين
  - استعادة النسخ الاحتياطية
  - تجاوز منع المخزون السالب
  - عرض الأرباح
  - تعديل الورديات المغلقة

### **المشرف (Supervisor):**
✅ صلاحيات إدارية واسعة
✅ يمكنه:
  - اعتماد المشتريات
  - اعتماد الجرد
  - اعتماد المنتجات
  - إلغاء الفواتير
  - عرض الأرباح
  - جميع التقارير
❌ لا يمكنه:
  - تعديل الأسعار
  - حذف البيانات
  - إدارة المستخدمين

### **الكاشير (Cashier):**
✅ صلاحيات البيع فقط
✅ يمكنه:
  - إنشاء فواتير
  - إضافة عملاء
  - تحصيل دفعات
  - فتح/إغلاق ورديته
  - عرض المنتجات (السعر والكمية فقط)
❌ لا يمكنه:
  - تعديل الأسعار
  - حذف الفواتير
  - عرض الأرباح
  - تعديل المخزون
  - عرض التقارير
  - البيع بالسالب

### **أمين المخزون (Stock Manager):**
✅ صلاحيات المخزون والمشتريات
✅ يمكنه:
  - إضافة فواتير شراء (قيد المراجعة)
  - بدء الجرد
  - عرض المخزون
  - عرض تكلفة الشراء
  - مرتجع المشتريات
❌ لا يمكنه:
  - اعتماد المشتريات
  - اعتماد الجرد
  - البيع
  - تعديل الأسعار
  - عرض الأرباح

## 🔄 **تدفق الاعتماد (Approval Workflow):**

### **المشتريات:**
```
1. أمين المخزون يضيف فاتورة شراء
   → Status: "قيد الانتظار"
   → is_approved: FALSE

2. المدير أو المشرف يراجعها
   → يعتمدها أو يرفضها

3. عند الاعتماد:
   → Status: "معتمد"
   → is_approved: TRUE
   → تضاف الكميات للمخزون تلقائياً
   → تحدث حسابات المورد
```

### **المنتجات الجديدة:**
```
1. موظف يضيف منتج
   → is_approved: FALSE
   → is_active: FALSE
   → المنتج لا يظهر في POS

2. المدير يعتمده
   → is_approved: TRUE
   → is_active: TRUE
   → يظهر في POS

3. إذا رفضه المدير
   → يبقى is_approved: FALSE
   → لا يظهر أبداً
```

### **الجرد:**
```
1. أمين المخزون يبدأ جرد
   → Status: "قيد التنفيذ"

2. يدخل الكميات الفعلية

3. يحسب النظام الفروقات تلقائياً

4. المدير يعتمد الجرد
   → Status: "معتمد"
   → تحديث المخزون تلقائياً
   → تسجيل الفروقات في inventory_movements
```
